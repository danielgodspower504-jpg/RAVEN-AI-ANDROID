# 🐦‍⬛ RAVEN

## YOUR PHONE. YOUR RULES.

RAVEN is a security-first AI command assistant designed for Android.

### Core Capabilities

- AI command center
- Voice assistant
- Notification intelligence
- Task and reminder management
- Night Shift
- Automation engine
- Activity logging
- Permission management
- Emergency automation stop
- BLACK DISTRICT business mode
- Modular AI provider architecture

### Android Stack

- Kotlin
- Jetpack Compose
- Android SDK
- Kotlin Coroutines
- Room
- WorkManager
- Notification Listener Service
- Accessibility Service where appropriate

### Backend

- Node.js
- REST API
- WebSocket support
- PostgreSQL
- Redis

### Security

RAVEN never bypasses authentication, Android security controls, passwords, OTPs, or protected information.

Sensitive and irreversible actions require user confirmation.
